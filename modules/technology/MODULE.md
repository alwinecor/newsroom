# 科技 / technology

状态：enabled。每周筛选 5–8 条具有国际意义的重要新闻。

重点：AI、foundation models、developer tools、major software/platform changes、semiconductors、major open-source projects、important research releases。

建议来源：OpenAI、Anthropic、Google / DeepMind、Microsoft、Meta、NVIDIA、AMD、TSMC、ASML、Apple、major GitHub projects、arXiv / research institutions、Reuters / FT / TechCrunch 等。不要要求每周所有来源都出现。优先使用原始公告的 URL；若只有可靠媒体报道，可使用符合编辑政策的媒体。

独立执行搜索、阅读原始来源、核实、重要性筛选、模块内部去重、中文摘要和 JSON 输出。同一事件多篇报道合并为一个 item，选择最直接可靠的原始链接。不得为凑数虚构新闻。

先遵循 pipeline/EDITORIAL_POLICY.md 和 TRANSLATION_POLICY.md，再读取本目录 schema.json。保留原始标题和来源信息。输出 data/issues/YYYY-MM-DD/technology.json；module 必须为 technology。ID 建议 technology-001，模块内唯一。窗口和日期遵循 PIPELINE.md。
